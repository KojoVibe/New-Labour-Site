# Assets Folder

This folder contains all images and media files for the Labour Department of Ghana website.

## Required Images

### Logo
- **File:** `ghana-coat-of-arms.png` or `labour-department-logo.png`
- **Description:** The official Labour Department of Ghana logo (the one you shared)
- **Recommended size:** 200x200px minimum
- **Format:** PNG with transparent background preferred

### Hero Section
- **File:** `workers-ghana.jpg`
- **Description:** Professional photo of Ghanaian workers or workplace scene
- **Recommended size:** 1200x800px
- **Format:** JPG

### News Images
- **File:** `news-1.jpg`
- **Description:** Labour Day celebration or workers' event
- **Recommended size:** 400x300px
- **Format:** JPG

- **File:** `news-2.jpg`
- **Description:** Skills training or education program
- **Recommended size:** 400x300px
- **Format:** JPG

- **File:** `news-3.jpg`
- **Description:** Government or legal documents/meeting
- **Recommended size:** 400x300px
- **Format:** JPG

## Notes

1. Save the Labour Department logo you shared as `labour-department-logo.png` in this folder
2. Update the HTML `src` attribute from `ghana-coat-of-arms.png` to `labour-department-logo.png` if needed
3. All images should be optimized for web use
4. Consider using WebP format for better performance if browser support allows
5. Always include appropriate alt text for accessibility
